Building with LLMs

What a model call is

The admissions agent runs on a large language model, or LLM: a program trained on huge amounts of text that writes a likely reply to whatever you send it.

Your code sends it some text and gets text back. That's one model call.

The model reads and writes in small pieces of text called tokens, and you pay for every token in and out.

Step through one model call
  1. 1A parent messages: "wat is fees for full stack?"
  2. 2Your code sends the model your rules plus that message.
  3. 3The model writes a reply, one token at a time.
  4. 4Your code checks the reply and sends it on WhatsApp.

What rules does it need?

Write the rules

On its own, a model doesn't know Northstar's fees or rules. It fills the gaps with guesses that sound confident.

So every call starts with instructions it must follow: who it is, the facts it may use, and what it must never do. These are called the system prompt.

Switch rules on and see how the reply changes

But your code needs more than a friendly reply.

Answers your code can use

Your code has decisions to make: is this about fees, does it need a person? It can't read a paragraph reliably.

So you also ask the model for a few fields in a fixed shape, in a format called JSON. The code reads the fields, and the friendly reply is just one of them.

Prices change often, and differ between models. Always check the current price list before you quote a client.

Let the model use tools

The model can't see today's calendar. But your code can.

So you tell the model which functions it may ask for, like find_slots. When it needs one, it replies with a request instead of an answer. Your code runs the function and sends the result back.

A function the model can ask your code to run is called a tool.

Step through one tool call
  1. them"Any counselling slot on Saturday morning?"
  2. modelAsks for a tool: find_slots(day="Sat 21 Nov", part="morning")
  3. codeChecks the calendar: Anand 11:00, Divya 10:00 and 11:00, Meera 10:00.
  4. modelGets those slots back, and writes: "Yes! Saturday at 10:00 or 11:00. Which suits you?"

Which tool does each message need?

Pick the right tool

The admissions agent has three tools: get_fee reads the current fee sheet, find_slots reads the counselling calendar, and hand_to_human passes the chat to a counsellor.

Choosing well is the model's job, but you must know the right answer, so you can test that it chooses well.

Which tool should the agent use?

Ask twice, and you may get two different answers.

Same question, different answers

A model picks each token with a little randomness. A setting called temperature controls how much.

High temperature gives more varied, creative wording. Low temperature gives nearly the same answer every time.

For fees and bookings, you want the same correct answer every time.
