Shipping it

Where it runs

The agent works on your laptop. Now it has to run all day, every day, for real parents.

Putting it somewhere real users can reach is called deploying it. Before you do, know every piece a message passes through, because each one can fail.

Follow one message through the live system
  1. WhatsAppA parent sends a message. WhatsApp passes it to Northstar's web address.
  2. serverYour code, on a server that's always on, receives it and hides personal details.
  3. modelYour code calls the model, which may ask for tools: fees or slots.
  4. checksThe guardrails check the reply.
  5. WhatsAppThe reply goes back to the parent.
  6. sheetThe lead and the chat are saved to the lead tracker.

Each piece needs a key. Where do keys go?

Keep keys secret

Your code proves who it is to WhatsApp and to the model company with secret codes called API keys. Anyone with the key can spend Northstar's money or read its messages.

So keys never go in the code, in a chat or on GitHub. They're stored on the server, in settings the code reads when it starts, called environment variables.

Sort each habit

Keys aren't the only secret.

Protect personal data

Enquiries carry phone numbers, emails and family stories. Kevin's first worry was exactly this.

Send the model only what it needs to answer. A phone number never helps it answer a fee question, so replace it with a placeholder before the call. India's data protection law, the DPDP Act, also expects you to collect and share as little as you need.

Keep the cost down

Models come in sizes. Big ones handle hard questions well but cost much more per call. Most enquiries are easy: fees, campuses, timings.

So send easy questions to a small, cheap model, and only hard ones to the big model. Sending each request to the right model is called routing.

Ready to switch it on? Not all at once.

Roll out slowly

Don't switch it on for everyone on day one. Start small, watch closely, then grow.

And keep one switch that turns the agent off and sends every chat back to counsellors, in seconds. Going back to the old way like that is called a rollback.

Step through Northstar's rollout
  1. week 1Counsellors chat with it themselves, trying to break it.
  2. week 2Live at night only, 9 pm to 8 am. Counsellors read every chat next morning.
  3. week 3All hours, for 1 in 4 chats. Compare first-reply times with the rest.
  4. week 4Everyone, if the numbers hold. The off switch stays ready.
